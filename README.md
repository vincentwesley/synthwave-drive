# Synthwave Drive
Endless neon wireframe road driven by beat detection of any song you load.

Develop: `npm install --ignore-scripts`, then `npm run dev`. Checks: `npm run typecheck`, `npm test`, `npm run e2e`.

- No secrets or env vars needed.
- No network calls: audio is processed locally in the browser and never uploaded.
- No data is stored.
