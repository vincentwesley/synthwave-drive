# Synthwave Drive
Endless neon wireframe road; beat detection on any song the user loads drives the scene. Audio stays local.

- Stack: Vite + TypeScript, three.js, Vitest, Playwright + axe. Node 24 (`.nvmrc`).
- Commands: `npm run dev | build | preview | typecheck | test | e2e`.
- Deploy: GitHub Pages (no headers, so CSP is a `<meta>` in `index.html`).
- Follows `../CLAUDE.md` house rules (dark default, `src/house/` kit, credits card last).
